# 智能稀疏多目标资产配置研究
## Sparse Multi-objective Asset Allocation

将收益、风险和异质市场信号纳入同一优化框架，并通过持仓数量约束控制投资组合复杂度。

本仓库是基于已有研究稿整理的**研究展示版**，介绍问题定义、模型结构和算法设计。当前不包含原论文全文、原始实现、数据集或可复现实验记录，也不将研究稿中的绩效数字作为已核验成果展示。

## 研究思路

- **多目标建模**：在收益与风险之外，加入情绪评分（ES）和主力意图评分（MFIS）两个信号目标，分析不同目标之间的权衡。
- **稀疏资产选择**：限制非零持仓数量，控制组合规模。稀疏持仓并不自动意味着低风险或低交易成本。
- **进化优化**：研究多目标进化搜索与自适应稀疏截断的结合，寻求一组候选权衡解，而非宣称存在唯一最优组合。
