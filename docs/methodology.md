# 模型与算法说明

本文档依据已有研究稿整理，介绍方法设计，不是原论文全文，也不是可执行算法规范。没有加入新的实证结论或替代原始实现。

## 1. 研究问题

传统均值—方差框架侧重收益与风险。本研究尝试将市场情绪与资金行为信号作为额外优化目标，并控制持仓数量，研究多个目标之间的权衡。

“主力意图评分”是原研究对一类代理信号的命名，不表示能够直接观测或准确识别市场参与者的真实意图。

## 2. 四目标模型

设候选资产数为 N，组合权重为 w，预期收益向量为 μ，收益协方差矩阵为 Σ。ES 和 MFIS 分别表示每项资产的情绪评分、主力意图评分。

优化目标：

- 最大化预期组合收益：wᵀμ。
- 最小化组合方差：wᵀΣw。
- 最大化加权情绪评分：Σᵢ wᵢ ESᵢ。
- 最大化加权主力意图评分：Σᵢ wᵢ MFISᵢ。

约束：

- Σᵢ wᵢ = 1。
- wᵢ ≥ 0。
- ‖w‖₀ ≤ K，即非零权重数量不超过 K。

这里 ‖w‖₀ 表示非零元素个数。四个目标按多目标问题处理，不应在没有规则说明的情况下直接合成为一个收益指标。候选解集还需要独立的组合选择规则才能形成一条可回测策略。

## 3. 信号定义的边界

研究稿将 ES 描述为涨停强度、连板动量、市场情绪分歧等子因子的综合；将 MFIS 描述为筹码吸收、恐慌盘、大单净流入等因子的综合。

这些描述尚不足以独立复现。实际实现还需确定原始字段、数据来源、计算公式、标准化方式、缺失值处理、信号时间戳与可用时点。当前文档不补造这些细节。

## 4. 进化搜索与稀疏截断

研究稿中的算法设计包含：

1. 初始化候选组合。
2. 非支配排序与选择。
3. 交叉和变异。
4. 对超过持仓上限 K 的候选组合应用稀疏截断。
5. 精英保留并继续迭代。

自适应截断的核心设想，是根据资产对多个目标的归一化贡献，以及动态目标权重，构造综合重要性评分。稿件描述了依据目标方向上的解分布调整权重的思路。

但完整实现仍需要明确：贡献度的具体公式、风险目标的方向处理、权重更新公式与频率、截断保留规则、平分处理、截断后的权重归一化、可行性修复、种群规模、终止条件和随机种子。本文档没有将这些缺失细节包装成已完成代码。

## 5. 参数与评估设计

稿件中的示例设定包括最大持仓数 K=15、过去 120 个交易日估计收益与协方差、月末调仓。它们属于稿件描述，不能单独证明相应实验已经运行或得到验证。

研究稿列出的比较对象包括等权重组合（EW）、均值—方差组合（MV）和双目标稀疏组合（Bi-Sparse）。公平比较还需统一股票池、可交易约束、信息可用时点、再平衡规则、交易成本以及调参预算。

## 6. 解释限制

稀疏约束可能降低持仓管理复杂度，也可能提高集中度风险。信号加入目标函数并不自动产生增量收益。算法是否有效，需要可追溯数据、完整实现、独立样本评估及适当稳健性检验支持。
